Controls

The default value-format="json" serialises selections into a single hidden input. Read it back on the server by parsing the JSON string:

js
app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
Description

A single hidden field carries the whole selection as a JSON array — no field-name juggling, no delimiters to escape. Ideal for modern JSON APIs.

html
<input type="hidden" name="languages"
  value='["js","ts"]'>

Value formats

Pick the serialisation that matches your backend. The component keeps its UI identical — only the shape of the submitted value changes.

value-format Hidden input value Use when
json ["js","ts"] Modern JSON backends
csv js,ts Classic form posts
array multiple inputs PHP-style name[]
✦ Tip

Set value-format once on the element and it applies to every submit — no wrapper JavaScript required. Combine it with the native required attribute to get browser-level validation for free.

!
Heads up The array format emits one hidden input per value. If your endpoint expects a single field, use json or csv instead — otherwise only the last value may survive server-side parsing.
