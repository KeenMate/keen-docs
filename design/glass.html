Read the JSON string on the server and parse it back into a real array before validating.

js
app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
Description

The component renders a single hidden input holding a JSON-encoded array. It posts cleanly with any standard <form>.

html
<input type="hidden" name="languages"
  value='["js","ts"]'>

Value formats

Pick the wire format that matches your backend. All three post through the same hidden-input mechanism.

value-formatHidden input valueUse when
json["js","ts"]Modern JSON backends
csvjs,tsClassic form posts
arraymultiple inputsPHP-style name[]
💡 Tip

Keep value-format in sync between the client component and your server parser. When in doubt, log the raw hidden-input value once — the output box in every demo above shows exactly what will land in req.body.

!
Heads up

The array format emits one input per selection. Make sure your framework groups repeated name[] fields into a list — some older stacks keep only the last value and silently drop the rest.
