Controls

The component serialises its selection into a hidden input on every change, so a normal form POST just works. Parse it back on the server: 

app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
Description

JSON is the default value-format. The hidden input carries a valid JSON array — ideal for modern backends that already speak JSON. 

<input type="hidden"
  name="languages"
  value='["js","ts"]'>

Value formats

The value-format attribute decides how the selection is written into the hidden input. Pick the shape that matches how your backend reads the form.

value-format Hidden input value Use when
json ["js","ts"] Modern JSON backends
csv js,ts Classic form posts
array multiple inputs PHP-style name[]
Tip

Prefer csv or array when a legacy framework can't parse a JSON string field. Both round-trip cleanly through a standard application/x-www-form-urlencoded submission — no client JavaScript required on the receiving end.

!
Heads up

The array format emits one hidden input per selected value. If your handler reads a single scalar field it will only see the last one — read the field as a list (e.g. request.form.getlist("languages[]")).
