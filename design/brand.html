FI01 — JSON Format (default)

The default serialization writes selected values as a JSON array into a hidden input, so any backend that already speaks JSON can read the field directly.

⚙ Controls

On the server, parse the hidden field back into an array. Node/Express reads the JSON body field directly:

js
app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
✦ Description

The component keeps a synced hidden input inside the form. Its value is a JSON-encoded array of the selected option values.

html
<input type="hidden"
  name="languages"
  value='["js","ts"]'>

Value formats

The value-format attribute controls exactly what lands in the submitted field. Pick the shape your backend already expects.

value-format Hidden input value Use when
json ["js","ts"] Modern JSON backends
csv js,ts Classic form posts
array multiple inputs PHP-style name[]
💡 Tip
:::col is a plain labelled column (no box). :::card — like this one — is the boxed variant with a colored header bar.
!
Heads up

With value-format="array" the component emits multiple inputs sharing one name[]. Make sure your framework merges repeated fields — some strict parsers keep only the last value.
