Controls

Parse the hidden field server-side. The value arrives as a JSON string, so decode it before use.

server.jscopy
app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
Description

The component renders a hidden input alongside the widget. Its value stays a JSON array of the selected option keys.

htmlcopy
<input type="hidden"
  name="languages"
  value='["js","ts"]'>

Big demos want more room

Some demos need width to breathe — a wide interactive surface with a narrow annotation rail beside it. Use an 80/20 column split so the live widget dominates while notes stay in view.

Notes

The csv format is ideal for classic form posts and CSV exports.

No JSON decode required on the server.

index.htmlcopy 
<script>import '@keenmate/web-multiselect';</script>

<web-multiselect
  value-format="csv"
  data-options="Prague,Vienna,Berlin" />

Value formats

Choose how the hidden input serializes the selection. The value-format attribute controls the wire shape.

value-formatHidden input valueUse when
json ["js","ts"] modern JSON backends
csv js,ts classic form posts
array multiple inputs PHP-style name[]
★ Tip

Set value-format="array" and give the field a name ending in [] to get one hidden input per selection — no server-side parsing needed for PHP, Rails, or Laravel.

!
Watch out

When using csv, option labels containing commas will break the split. Prefer json or array if your option values can contain delimiters.
