Read the hidden input on your server and parse the JSON array back into a list.

js server.js
app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
Description

The component renders a single hidden field. Its value is a JSON-encoded array kept in sync as the user selects.

html rendered
<input type="hidden"
  name="languages"
  value='["js","ts"]'>

Notes

The csv format is friendlier for classic form posts and PHP-style handlers that don't decode JSON.

  import '@keenmate/web-multiselect';
</script>

<web-multiselect
  value-format="csv"
  data-options="Prague,Vienna,Berlin" />

#Value formats

Pick the wire format that matches your backend. All three keep a single source of truth in sync with the selection.

value-format Hidden input value Use when
json ["js","ts"] modern JSON backends
csv js,ts classic form posts
array multiple inputs PHP-style name[]
✦Tip

:::col is a plain labelled column (no box). :::card — like this one — is the boxed variant.
