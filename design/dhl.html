Controls

The component writes a hidden input on every change. Read it on the server exactly as posted — no client glue required.

js
app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
Description

By default value-format="json" serializes the selection as a JSON array. Ideal for modern backends that already speak JSON bodies.

html
<input type="hidden"
  name="languages"
  value='["js","ts"]'>

Value formats

Pick the serialization that matches the backend you post to. All three are lossless round-trips of the same selection.

value-format Hidden input value Use when
json ["js","ts"] modern JSON backends
csv js,ts classic form posts
array multiple inputs PHP-style name[]
Tip

:::col is a plain labelled column (no box). :::card — like this one — is the boxed variant.

!
Watch out

With value-format="array" the component emits one hidden input per selection. Your framework must merge same-named fields into a list — most do, but confirm before shipping to production.
