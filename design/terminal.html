Controls

On the server, parse the hidden field as JSON. The value is always a well-formed array — no delimiter guessing.

js
app.post('/submit', (req, res) => {
  const langs = JSON.parse(req.body.languages);
});
Description

A single hidden input mirrors the current selection. It updates on every change and posts natively with the form.

html
<input type="hidden"
  name="languages"
  value='["js","ts"]'>

Notes

The csv format posts one string. Great for classic backends that split on commas.

svelte
<script>import '@keenmate/web-multiselect';</script>

<web-multiselect
  value-format="csv"
  data-options="Prague,Vienna,Berlin" />

Value formats

Pick the value-format that matches how your backend reads form data.

value-format Hidden input value Use when
json ["js","ts"] modern JSON backends
csv js,ts classic form posts
array multiple inputs PHP-style name[]
Tip

:::col is a plain labelled column (no box). :::card — like this one — is the boxed variant.

!
Heads up

The array format emits one hidden input per value. If your framework de-duplicates repeated field names, prefer json instead.
